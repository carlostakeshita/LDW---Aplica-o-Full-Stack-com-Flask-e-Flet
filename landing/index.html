Minecraft Notes

Notas temáticas com backend Flask e cliente Flet — projeto demo com visual inspirado em Minecraft.

Abrir Swagger

Descrição

Aplicação demo que permite listar e criar notas. O backend é um serviço Flask organizado com Blueprints e expõe uma spec OpenAPI. O cliente é uma aplicação desktop em Flet que consome a API.

Backend

Flask + Blueprints. Endpoints documentados em OpenAPI.

Frontend

Cliente em Flet com interface inspirada no visual do Minecraft.

Dados

Armazenamento em memória (exemplo). Não requer banco de dados.

Como executar

python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
python -m backend.app
python flet_app.py

Recomenda-se Python 3.10/3.11 para compatibilidade com todas as dependências do Flet. Abra /apidocs para ver a documentação da API.

Endpoints

GET /api/notes/

Lista todas as notas.

GET /api/notes/<id>

Retorna a nota especificada pelo id.

POST /api/notes/

Cria nova nota (JSON: {"title","content"}).
