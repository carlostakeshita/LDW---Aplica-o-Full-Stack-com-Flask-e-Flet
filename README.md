# Notes Project

Projeto demo com backend em Flask, frontend em Flet e landing page com Tailwind.

Como executar (local):

1. Criar e ativar virtualenv (opcional)

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate # macOS / Linux
```

2. Instalar dependências

```bash
pip install -r requirements.txt
```

3. Rodar backend

```bash
python -m backend.app
```

Swagger UI: http://127.0.0.1:5000/apidocs

4. Rodar frontend (Flet)

```bash
python flet_app.py
```

5. Abrir landing

Abra `landing/index.html` no navegador.
